## 返工账（为什么必须按层）

| 越层动作 | 后果 |
|----------|------|
| Phase A class 私有 own 槽（L4 Class 扩语义） | language/statements **1299→1294（−5）** |
| Promise 组合器扩 NPC 未先收 IteratorStep 对象检查 | Promise CRASH **2→9**，4 条原 PASS 变 SIGSEGV |
| TypedArray W1 Design C（L5 在 L2 未满时） | gen2 `not a function`，整波回滚 |
| for-await 与 Object/Array 并行 | 改的是 GetIterator 症状；L2 泛型一动，脱糖全废 |

**规则：同层只稳定债或补已交付面的缺口；扩语义必须下层门禁绿。**

## 执行纪律

1. 同时刻只允许一个 agent 写 `object/index.js`
2. 同时刻只允许一个 agent 写 `members.js`（自举热路径，禁止顺手大重构）
3. Array / Object 关键路径串行；禁 `_array_length`/`_array_get` prologue
4. RegExp `\p{}` / TypedArray / for-await：**依赖未满，不立项**
5. 区测不得覆盖官方 `last_run*`
6. 每层收口：`bootstrap-gate` → 官方 `stride 5` → 更新本文件 + 台账
7. 跨层依赖未满足时记阻塞，不硬冲
8. 扩语义导致 CRASH 上升或下层 PASS 回退 → 先收债，再谈下一层
