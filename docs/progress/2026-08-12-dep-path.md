# 按 JS 依赖路径实施（2026-08-12）

> 上位：`docs/progress/2026-08-12-orchestration.md`  
> 原则：**下层未稳不扩上层**；同层可并行，跨层串行；门禁后才算交付。

## 依赖图（执行序）

```
L0  Value / 内部方法
    ToPrimitive / ToNumber / SameValue*
        │
L1  Object 模型  ◀── 当前主攻
    [[Get]]/[[Set]]/[[DefineOwnProperty]]/[[Delete]]/[[HasProperty]]
    描述符 · defineProperty* · gOPD · keys/枚举
        │
L2  Array（exotic length/索引 + 真 hole）  ◀── 已部分交付，跟随 Object
        │
L3a String          L3b Function（name/length/call/construct）
        │                     │
L4  RegExp ← String     L4  Class / Promise / Map / Set / Date ← Function
        │
L5  TypedArray / ArrayBuffer ← Array + Object
```

## 执行纪律

1. 同时刻只允许一个 agent 写 `object/index.js`
2. RegExp / TypedArray / for-await 不得与 Object 主轨并行覆盖 `last_run*`
3. 每层收口：`bootstrap-gate` → 官方 `stride 5` → 更新台账
4. 跨层依赖未满足时记阻塞，不硬冲
