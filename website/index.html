04CAPABILITIES & HONEST SCOPE

现代语法。
原生心智。

把熟悉的现代 JavaScript 语法，直接编译为无 VM、无依赖的原生二进制。

/ 01 SYNTAX

现代 JS 与模块

完整支持箭头函数、闭包、ES6 类（继承/静态/getter）、async/await、Promise、解构、BigInt、模板字符串、for-of/for-in 与 ESM 模块导入导出；内置纯 JS 实现的全参数 JSON.stringify 与 JSON.parse。

/ 02 RUNTIME

Node 核心库 Shim

原生实现 console、process、fs、path、timers、os，并包含真实 crypto（AES/SHA/HMAC/PBKDF2/HKDF）、zlib（DEFLATE/gzip）、net 与 http 网络栈等实用子集。

/ 03 PIPELINE

分代 GC 与全栈手写

缺省开启分代式垃圾回收器（sticky mark-bit minor + Go 式 full 步调，峰值 RSS 降 ~30%）；手写词法分析、Pratt 语法解析、线性扫描寄存器分配与属性站点缓存 IC，零三方库可审计。

WHERE IT FITS

最适合的场景

  • ✔
    单二进制分发的 CLI 命令行工具：单一静态文件部署，免去分发 Node.js 与 node_modules 的负担。
  • ✔
    启动延迟敏感的短生命周期进程：~2ms 原生毫秒级启动，消除传统 VM 庞大启动开销。
  • ✔
    安全与审计要求极高的独立环境：从 .js 源码到原生机器码零不透明第三方依赖，全流程可验证。
KNOWN GAPS

现阶段不适合的场景

  • ✖
    长驻计算密集型服务：目前尚无多态 JIT 编译器，密集数值热循环建议使用 V8/JSC。
  • ✖
    直接运行任意未适配 npm 包：当前为核心 Node API 子集，复杂三方生态正在逐步推进。
  • ✖
    动态加载 C++ Native Addon：封闭世界 AOT 静态单二进制模型不兼容 .node 动态插件。
